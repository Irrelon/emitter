deferEmit(eventName, …data)

Queues an event to be fired. This has automatic de-bouncing so that any events of the same type that occur within 100 milliseconds of a previous one will all be wrapped into a single emit rather than emitting tons of events for lots of chained inserts etc. Only the data from the last de-bounced event will be emitted.

Examples
#Emit an Event

#Emit an Event With Data Object

#Emit an Event With Multiple Data Values
    // Emit the event named "hello"

#Listen for Event Data
    // Set a listener to listen for the data (multiple values emitted
    // from an event are passed as function arguments)
	   myEntity.on('hello', function (arg1, arg2) {
        console.log("Arguments:", arg1, arg2);
        return "foo";
    }

    // Emit the event named "hello"
    // The result is returned as an array of all return values
    // from all the listeners for the event
    const result = myEntity.emit('hello', 'data1', 'data2');
      console.log("Result:", result);

    // The console output is:
    //	Arguments: data1 data2
    //	Result: ["foo"]

rpc(eventName, …data) → {number}

Call an event listener by name. The `rpc()` function differs from `emit()` in that it will only call and return data from the first event listener for the event rather than all event listeners. If you have more than one event listener assigned to the event, all others except the first will be ignored and will not receive the event.
Parameters:
Name Type Attributes Description
eventName The name of the event to call the listener for.
